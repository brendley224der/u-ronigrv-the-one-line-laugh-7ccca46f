A tiny pure-stdlib Python program that writes one original one-liner — about a printer that only jams when you're already late — to /output/entry.txt for make.fun's The One-Line Laugh bounty. The program checks its own line against the house gate (one sentence, 1–200 characters) before writing it.

## Run it

```sh
python3 main.py
```
